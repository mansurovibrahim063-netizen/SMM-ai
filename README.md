# KONTENT GALEREYASI — AI SMM Studio

Telegram, Instagram va YouTube uchun AI yordamida post matni va oblojka (muqova) tayyorlaydigan sahifa. O'zbek va rus tillarida ishlaydi.

## Ishlatish

`index.html` faylini brauzerda oching. O'rnatish shart emas.

Sahifa Google Gemini orqali ishlaydi. Birinchi marta ochganda sozlamalarga Gemini API kalitingizni kiriting. Kalitni https://aistudio.google.com/apikey sahifasidan olasiz. Kalit faqat sizning brauzeringizda saqlanadi va bu repozitoriyga yozilmaydi.

## Internetga chiqarish (GitHub Pages)

1. Repozitoriyda **Settings → Pages** bo'limini oching.
2. **Branch** maydonida `main` ni tanlang, papka `/ (root)` bo'lsin, keyin **Save** tugmasini bosing.
3. Bir-ikki daqiqadan keyin sahifa `https://mansurovibrahim063-netizen.github.io/SMM-ai/` manzilida ochiladi.
